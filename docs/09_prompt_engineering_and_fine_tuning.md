# 09. Prompt Engineering and Fine-Tuning

Generative AI relies heavily on **how models are prompted and customized**.

---

## 1. Prompt Engineering
- **Definition:** Crafting input prompts to guide model outputs.  
- **Techniques:**
  - Clear instructions  
  - Contextual examples  
  - Few-shot prompting
- **Importance:** Small changes in prompts can drastically affect output quality.

---

## 2. Fine-Tuning
- **Definition:** Adapting a pre-trained model for specific tasks or domains.  
- **Techniques:**
  - **Full model fine-tuning:** Updates all parameters.  
  - **Parameter-efficient fine-tuning (LoRA):** Updates only a small subset.  
  - **Reinforcement Learning with Human Feedback (RLHF):** Aligns outputs with human preferences.

---

## 3. Applications
- Domain-specific chatbots  
- Industry-specific content generation  
- Enhanced creativity and control in multimodal outputs

---

## 4. Summary
Prompt engineering and fine-tuning are **critical tools** for controlling, customizing, and optimizing Generative AI models.
