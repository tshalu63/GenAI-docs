# 01. Introduction to Generative AI

Generative AI (GenAI) refers to AI systems capable of **creating new content**—text, images, audio, code, or video—rather than only analyzing existing data.

### Key Points

- Unlike traditional AI, GenAI **creates content**, not just predicts.
- Can be used for **creativity, automation, and innovation**.
- Examples:
  - Text: ChatGPT, GPT-4  
  - Images: DALL·E, MidJourney, Stable Diffusion  
  - Audio: MusicLM, Jukebox  
  - Code: GitHub Copilot
