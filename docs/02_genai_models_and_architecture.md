# 02. Machine Learning Basics for Generative AI

Generative AI builds on **machine learning (ML)** principles. Understanding ML is crucial to grasp how GenAI models learn patterns from data and generate new content.

---

## 1. What is Machine Learning?
- **Definition:** ML is a subset of AI where systems **learn patterns from data** without explicit programming.  
- **Types of ML:**
  - **Supervised Learning:** Learns from labeled data (e.g., image classification).  
  - **Unsupervised Learning:** Finds patterns in unlabeled data (e.g., clustering).  
  - **Reinforcement Learning:** Learns by **trial-and-error** to maximize rewards.

---

## 2. Role in Generative AI
- Generative AI relies heavily on **deep learning** (a branch of ML).  
- Models **learn probability distributions** of data to create new, realistic outputs (text, images, audio).  
- Example: A text generation model predicts the next word based on training on large corpora.

---

## 3. Key Concepts
- **Feature Extraction:** Converting raw data into meaningful representations.  
- **Overfitting vs Underfitting:** Ensuring models generalize to new data.  
- **Loss Functions:** Quantifies model errors; guides learning.  
- **Optimization:** Gradient descent, Adam optimizer, etc.

---

## 4. Summary
ML is the **foundation of Generative AI**, providing the tools and techniques to **learn from data, capture patterns, and enable creative content generation**.
